SLAO STORE COMPLETE v20 (COMPLETE CUSTOMER DETAILS SAVED IN ADMIN PORTAL)
=================================================================================

1. HOW TO RUN:
   - Open terminal inside 'SLAO_Store_Complete-v20'
   - Run: npm install
   - Run: npm start
   - Storefront: http://localhost:3000
   - Admin Portal: http://localhost:3000/admin-orders.html

2. UPDATE IN v20:
   - Whenever a customer places an order or updates their account profile, their full details (Name, Primary Phone, Alternative Phone, City, Province, Postal Code, Full Delivery Address, Email, and Last Order ID) are automatically saved in the backend database and shown under the 'Customers' tab in admin-orders.html.
